# Getting help with Beryl

- **How do I ...?** Start with the guides:
  [hashes and MACs](docs/crypto/hashes-and-macs.md),
  [ciphers and AEADs](docs/crypto/ciphers-and-aeads.md),
  [public keys](docs/crypto/public-key.md) and
  [certificates](docs/certificates.md).
- **A wrong result, a refused valid input or a crash.**
  [Open a bug report](https://github.com/amberframework/beryl/issues/new/choose)
  with the smallest input that shows it.
- **A way to learn a secret, forge something or get a bad chain verified.**
  Report it privately: see [SECURITY.md](SECURITY.md).
- **Amber questions.** [amberframework.org](https://amberframework.org).
- **Paid help.** [AgentC Consulting](https://agentc.consulting) builds and
  maintains Beryl and Amber: agent_c@agentc.consulting.
